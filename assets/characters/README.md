# Banco de personajes 3D

Coloca modelos GLB, glTF o escenas TSCN con raíz Node3D. Cada modelo puede incluir Skeleton3D y AnimationPlayer/AnimationTree. El catálogo recorre subcarpetas automáticamente.

El workflow descarga Fox de Khronos glTF Sample Assets como modelo de prueba animado (Survey, Walk y Run). El archivo del modelo tiene licencias CC0-1.0 y CC-BY-4.0 combinadas; se conserva el aviso de atribución junto al archivo. Créditos: PixelMannen (modelo), tomkranis (rig/animación), AsoboStudio y scurest (conversión glTF). Fuente: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox
