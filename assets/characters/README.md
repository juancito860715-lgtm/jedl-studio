# Banco de personajes 3D

Directorio reservado para personajes 3D locales de JEDL Studio. Cada recurso que se incorpore debe incluir su identificador estable, licencia exacta, evidencia de redistribución, SHA-256 y dependencias locales.

El catálogo inicial del Hito 1 utiliza un personaje geométrico propio en `assets/gallery/3d/`. No se descargan modelos ni se consultan servicios externos durante la ejecución de la app.
